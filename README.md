# Проект: ТОРТЫ

Учебный Vue-проект по теме тортов на заказ.

## Основная идея

Сайт помогает пользователю выбрать пример торта, зарегистрироваться, войти в личный кабинет, собрать торт в конструкторе, рассчитать стоимость и отправить заявку.

## Что реализовано

- Каталог примеров тортов
- Карточка торта с отдельным URL
- Дочерние разделы карточки: описание, состав, отзывы
- Регистрация пользователей
- Авторизация пользователей
- Личный кабинет
- Редактирование профиля
- Конструктор торта
- Автоматический расчёт цены
- Предпросмотр заказа
- Загрузка картинки-референса
- Форма заявки с валидацией
- История заказов текущего пользователя
- Избранное
- Админ-раздел
- Добавление, редактирование и удаление примеров тортов
- Список пользователей для администратора
- Защита маршрутов через meta и beforeEach
- Страница 404
- Подготовка к GitHub Pages

## Логика авторизации

Гость может смотреть главную страницу и каталог.

Для оформления заказа через конструктор пользователь должен войти в аккаунт. После входа он получает доступ к личному кабинету, истории своих заказов и отправке заявок.

Администратор входит через обычную форму входа и получает доступ к админ-разделу.

## Сборка

```bash
npm run build
```

## Публикация на GitHub Pages

1. Создать публичный репозиторий на GitHub.
2. Заменить `YOUR-NICK` в `package.json` на свой ник.
3. Если название репозитория отличается, заменить `vue-cakes-practice-auth-final` в `package.json` и `vite.config.js`.
4. Выполнить:
```bash
npm install
npm run predeploy
npm run deploy
```
5. В настройках GitHub Pages выбрать ветку `gh-pages`.

## Работа с ветками

Изменения не отправляются сразу в main. Каждый участник работает в своей ветке, делает минимум два коммита, затем создаёт Pull Request в main.
