# ПРОЕКТ: ТÓРТЫ

Учебный SPA-проект на Vue 3 для заказа тортов.

## Функционал

- каталог тортов
- фильтрация по категориям
- страница подробного описания торта
- добавление в избранное
- регистрация и авторизация
- личный кабинет пользователя
- конструктор индивидуального торта
- расчет стоимости заказа
- история заказов
- админ-панель
- управление пользователями
